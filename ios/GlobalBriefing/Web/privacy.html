로그인, 광고, 분석 SDK, 위치·연락처·사진 접근을 사용하지 않습니다. 읽기 설정, 저장한 브리핑, 단어장과 조회 결과는 기기에 보관하며 앱 운영자에게 별도로 업로드하지 않습니다. 운영체제 백업에 포함될 수 있습니다. 단어장은 편집 기능으로 삭제할 수 있고, 앱을 삭제하면 앱 저장 데이터도 제거됩니다.

뉴스 갱신에는 GitHub Pages를 사용합니다. 온라인 단어 조회는 설정에서 허용한 경우에만 사용합니다. Free Dictionary API에는 영어 단어가, MyMemory에는 영어 단어 또는 영어 뜻풀이가 전송됩니다. 각 서비스는 IP 주소 등 일반 접속 정보를 처리할 수 있습니다. 설정에서 온라인 조회를 끄면 새 조회 요청을 중단합니다. 자동 번역에는 오류와 사용량 제한이 있을 수 있습니다.

외부 원문·지원 링크에는 각 서비스의 개인정보 정책이 적용됩니다. 외부 서비스의 보관·삭제 정책은 해당 서비스에서 확인하세요.
