# GlobalBriefing 출시 보완 계획

2026-10-13. 현재 빌드는 테스트용이며 심사 통과를 보장하지 않습니다.

## 적용한 보완

- 고정 앱 제목과 자연스럽게 스크롤하는 기사 제목을 구분하고 중복 제목을 제거했습니다.
- 하단 사전은 본문 글자 크기와 분리한 작은 2줄 표시로 바꿨습니다. 키보드·접근성 포커스로 전체 뜻을 펼칠 수 있습니다.
- 네이티브 영한사전, 단어 저장·삭제·오프라인 복습, 새로고침·공유·설정 메뉴를 제공합니다.
- 읽기 화면을 앱에 내장합니다. 뉴스 데이터만 갱신하며 연결 실패 시 마지막 뉴스 또는 내장 브리핑을 표시합니다. 날짜를 현재 날짜로 위장하지 않습니다.
- 온라인 조회는 별도 허용 설정과 자동 번역 표시를 제공합니다.
- 앱 내 개인정보·지원·라이선스 안내와 공개 개인정보 페이지, UserDefaults 사용 사유를 담은 개인정보 매니페스트를 추가했습니다.

## 제출 전 반드시 해결할 사항

1. **뉴스 재사용 권리**: 공개 RSS라는 사실만으로 App Store 재배포·상업 사용 권리가 확보되지는 않습니다. Guardian의 RSS 안내는 개인·비상업 용도를 명시합니다. BBC와 Guardian의 현재 조건 및 앱 용도에 맞는 허가를 확인하고, 필요하면 허가된 출처로 교체해야 합니다. 이 작업에서는 이용권을 구매하거나 권리자에게 연락하지 않았습니다.
2. **외부 번역 서비스**: Free Dictionary API·MyMemory의 앱 사용 조건, 개인정보 보관 방식과 사용량 제한을 확인해야 합니다. 개인정보 라벨은 제3자의 실제 처리 방식까지 반영해 App Store Connect에서 작성해야 합니다. 매니페스트는 해당 라벨을 대신하지 않습니다.
3. **최소 기능 심사**: 독립적인 사전·단어장·오프라인 읽기 기능을 실제 심사 노트에서 설명하고 화면을 제공해야 합니다. WebKit을 사용한다는 사실을 숨기거나 단순 뉴스 모음 앱의 위험이 사라졌다고 주장하지 않습니다.
4. **스토어 등록**: 연령 등급은 뉴스·사전의 실제 콘텐츠에 맞게 작성합니다. 앱 설명은 영어 뉴스 읽기·단어 학습 기능에 맞추고, 실시간 뉴스·전문 기사 요약·검증된 번역이라고 과장하지 않습니다. 아이폰 스크린샷, 지원 URL, 개인정보 URL, 앱 소유자 연락처를 확인합니다.
5. **실기기 확인**: 작은 화면과 큰 글꼴, VoiceOver, 비행기 모드, 재실행 후 단어장 유지, 네트워크·조회 한도 오류를 확인하고 TestFlight 테스트를 거친 후 제출합니다.

## 심사 노트에 설명할 기능

로그인 없이 이용합니다. 첫 화면에서 영어 단어를 누르면 하단에 뜻이 표시됩니다. ‘현재 단어 저장’과 ‘내 단어장’ 메뉴에서 학습 단어를 보관·복습할 수 있습니다. 영한사전은 네트워크 없이 검색 가능합니다. 온라인 조회는 설정에서 사용자가 허용해야 하며 자동 번역임을 표시합니다. 원문 출처·발행 시각·브리핑 수집 시각을 제공합니다.
